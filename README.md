# Signals Prototype

A mobile-first Next.js prototype for Signals, an emotional wellness app for silently sending care and presence.

## Run Locally

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## Screens

- Home Feed
- Send Signal
- Choose Recipient
- Signal Sent Confirmation
- Profile

The app uses local mock data only. Sending a signal updates the in-memory feed at the top of the current session.
